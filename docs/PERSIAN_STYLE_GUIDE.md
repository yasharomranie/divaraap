# واژه‌نامه و نگارش فارسی

| اصطلاح | متن رابط |
|---|---|
| Listing | آگهی |
| Post listing | ثبت آگهی |
| Favorites | نشان‌شده‌ها |
| Inbox | پیام‌ها |
| Dashboard | پیشخوان |
| Login | ورود |
| Register | ثبت‌نام |
| Profile | پروفایل |
| Status | وضعیت |
| Featured | ویژه |

لحن روشن و محترمانه باشد؛ خطا مسیر ادامه را توضیح دهد. نیم‌فاصله و «ی» و «ک» فارسی رعایت شوند. کلیدهای ترجمه، placeholderهایی مانند :count و :date و قواعد جمع حفظ شوند. نام برند OpenClassify و شناسه‌های کد انگلیسی می‌مانند.

فونت رابط وزیرمتن محلی است. متن فارسی خوانا و جهت ایمیل، URL و تلفن مناسب باشد. ترجمهٔ رابط از تبدیل تاریخ، ارز و داده‌های نمونه جدا است و در فازهای مرتبط پیگیری می‌شود.
