# رابط تطبیقی آدوراکس

طراحی با استفاده از اسکیل نصب‌شدهٔ UI/UX Pro Max و تحلیل ساختار با Graphify انجام شده است. قالب Laravel، Blade و Filament حفظ شده و وابستگی یا CDN تازه‌ای اضافه نشده است.

## موبایل

- منوی ثابت پنج‌گانه: خانه، کاوش، ثبت آگهی، پیام‌ها و حساب من. مسیر فعال با متن، زمینه و `aria-current` مشخص می‌شود.
- کاربر مهمان برای ثبت آگهی، پیام‌ها و حساب به ورود هدایت می‌شود؛ کاربر واردشده به مسیر واقعی خودش می‌رود.
- فاصلهٔ پایین صفحه و safe area برای نوار سیستم گوشی حفظ می‌شود. نوار تماس آگهی بالای منوی اصلی قرار می‌گیرد.
- هنگام باز شدن صفحه‌کلید و کاهش محسوس ارتفاع viewport، نوار پایین سایت پنهان می‌شود تا فضای ورودی باقی بماند.
- صفحهٔ ورود بدون نوار ثابت است. منوی کشویی با Escape بسته می‌شود، فوکوس در آن می‌ماند و هنگام خروج به دکمهٔ بازکننده برمی‌گردد.

## دسکتاپ و مدیریت

- هدر کامل، جست‌وجو، منوی دسته‌بندی، بخش معرفی دو ستونی و شبکهٔ چهارستونی آگهی‌ها از عرض ۱۰۲۴ پیکسل نمایش داده می‌شوند.
- پنل مدیریت نوار سریع مخصوص خودش را در موبایل دارد؛ منوی کامل از «بیشتر» در دسترس است.
- تنظیمات عمومی به هویت سایت، اسلایدها، زبان و موقعیت، ارتباط و سرویس‌های متصل تقسیم شده‌اند. نام فیلدها و داده‌های ذخیره‌شده تغییر نکرده‌اند.
- رنگ‌ها و اندازهٔ نوشته‌ها همچنان از طراحی ظاهری کنترل می‌شوند؛ اندازهٔ نوشتهٔ منوی پایین نیز به آن اضافه شده است. ظاهر مدیریت برای حفظ خوانایی مستقل است.
- وزیرمتن، CSS و JavaScript محلی هستند. انیمیشن تازه‌ای افزوده نشده است.

## بررسی

صفحات اصلی، جست‌وجو، موقعیت، فیلترها، ورود، پنل کاربر، پیام‌ها و تنظیمات مدیریت در مرورگر بررسی شدند. عرض‌های ۳۲۰، ۳۷۵، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل، نبود سرریز افقی، وضعیت مسیر فعال، اندازهٔ لمس، فاصلهٔ نوارهای ثابت، راست‌چین و خطاهای JavaScript بررسی شدند. تصاویر نمونه در `docs/screenshots/app-redesign-*.png` قرار دارند و از داده‌های محیط توسعه گرفته شده‌اند.
