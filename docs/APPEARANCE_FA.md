# طراحی ظاهری

در پنل مدیریت به «تنظیمات ← طراحی ظاهری» بروید. این صفحه فقط برای مدیر قابل دسترسی است.

- ۱۹ رنگ برای متن، عنوان، زمینه، هدر، فوتر، قیمت، دکمه‌ها، بنر و وضعیت‌ها قابل تنظیم است.
- اندازهٔ نوشتهٔ ۴۹ بخش، از عنوان صفحه و کارت آگهی تا فرم، پیام و فوتر، برای موبایل و دسکتاپ جدا تنظیم می‌شود.
- موبایل عرض کمتر از ۱۰۲۴ پیکسل و دسکتاپ از ۱۰۲۴ پیکسل است. مقادیر بین ۱۰ و ۷۲ پیکسل پذیرفته می‌شوند و بزرگ‌نمایی مرورگر پشتیبانی می‌شود.
- پیش‌نمایش زنده یک نمونهٔ نمایشی از رنگ‌ها و نوشته‌هاست. تغییرات فرم تا قبل از ذخیره روی سایت اعمال نمی‌شوند.
- «بازگرداندن پیش‌فرض‌ها» فقط فرم را بازنشانی می‌کند؛ برای انتشار آن، ذخیره را بزنید.
- «مشاهدهٔ سایت ذخیره‌شده» سایت را با تنظیمات منتشرشده باز می‌کند.

تنظیمات روی صفحات عمومی، ورود و پنل کاربری اعمال می‌شوند. ظاهر پنل مدیریت مستقل می‌ماند. فونت وزیرمتن و تمام فایل‌های مورد نیاز محلی هستند. برای متن و زمینه رنگ‌هایی با اختلاف روشنایی کافی انتخاب کنید؛ متن دکمه‌های اصلی و تأکیدی خودکار سیاه یا سفید می‌شود.

داده‌ها در گروه `appearance` جدول `settings` ذخیره می‌شوند. دیپلوی، مهاجرت افزایشی تنظیمات را اجرا می‌کند و مقادیر موجود را نگه می‌دارد. فایل `.env`، فایل‌های کاربر و اطلاعات اتصال دیتابیس از این قابلیت تغییری نمی‌گیرند.

برای افزودن بخش تازه در توسعه، مشخصات فونت و انتخابگر CSS آن را در `App\Support\AppearanceTheme` و ترجمه‌های ماژول Site ثبت کنید. مقادیر هنگام ذخیره و نمایش اعتبارسنجی می‌شوند؛ CSS دلخواه پذیرفته نمی‌شود.
