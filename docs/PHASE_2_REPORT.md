# فاز ۲ — فارسی، RTL و وزیرمتن محلی

وضعیت: تکمیل و در محیط فعلی تأیید شده است. ترجمهٔ کامل ماژول‌ها و داده‌های نمونه طبق فازهای بعد ادامه می‌یابد.

## تغییرات

- fa و عنوان «فارسی» به سایت، تنظیمات و انتخاب زبان پنل مدیریت اضافه شدند؛ نام زبان‌ها از config مشترک خوانده می‌شود.
- config و .env.example پیش‌فرض فارسی دارند. نصب تازهٔ تنظیمات از config پیروی می‌کند. تنظیمات ذخیره‌شدهٔ نصب‌های قبلی بازنویسی نمی‌شوند؛ فقط دیتابیس توسعهٔ همین محیط روی فارسی تنظیم شد.
- فارسی و عربی RTL و انگلیسی LTR هستند. انتخاب صریح زبان در session حفظ می‌شود؛ در مدیریت، انتخاب صریح مقدم است و سپس پیش‌فرض سایت قبل از زبان مرورگر استفاده می‌شود.
- وزیرمتن متغیر در سایت و Filament از فایل‌های خود پروژه بارگذاری می‌شود. وزن‌های ۱۰۰ تا ۹۰۰، unicode-range و font-display: swap دارد.
- متن فارسی اندازهٔ پایهٔ ۱۶px، فاصلهٔ خطوط مناسب و فاصلهٔ حروف صفر دارد. ورودی ایمیل، URL و تلفن LTR باقی می‌مانند.
- ۱۰۱ کلید Site و ۳۳ کلید User ترجمه شدند. authentication، validation، pagination، password reset و پیام‌های عمومی Laravel فارسی شدند. کلیدها و placeholderها حفظ شده‌اند.

## منبع فونت و ترجمه

فونت‌ها در `public/assets/fonts/vazirmatn/` ثبت شده‌اند: font.css، سه فایل WOFF2 برای فارسی/عربی و لاتین، LICENSE از نوع SIL OFL 1.1، metadata.json و SOURCE.json همراه checksumها. منبع اصلی Vazirmatn و توزیع استفاده‌شده `@fontsource-variable/vazirmatn@5.3.0` است. باینری‌ها تغییر نکرده‌اند؛ فونت وابستگی runtime به npm یا CDN ندارد. مسیر ignored عمومی public/fonts استفاده نشده است.

ترجمه‌های عمومی Laravel از commit مشخص Laravel-Lang/lang گرفته شدند؛ منبع و مجوز MIT در `lang/fa/SOURCE.md` و `lang/fa/LICENSE` هستند. ترجمه‌های Site و User برای همین پروژه نوشته شدند.

## ادامه

دسته‌بندی‌ها، شهرها، عنوان و متن آگهی‌ها و صفحات CMS دادهٔ دیتابیس هستند و خودکار ترجمه نمی‌شوند. برخی برچسب‌های ثابت ماژول‌های دیگر هنوز انگلیسی‌اند؛ فازهای ۳ تا ۵ آن‌ها را پوشش می‌دهند. تاریخ شمسی، ارز و اعداد در فاز ۶ هستند.

در نصب موجود، APP_LOCALE=fa تنظیم و در تنظیمات عمومی نیز فارسی انتخاب شود؛ انتخاب قبلی کاربران حفظ می‌شود. وزیرمتن به صورت محلی برای همهٔ زبان‌ها استفاده می‌شود.
