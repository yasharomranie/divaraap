# فاز ۷: کیفیت و آمادگی انتشار

تاریخ اجرا: ۲۰۲۶-۱۰-۱۵. بررسی و اصلاحات محلی تکمیل شد؛ اجرای نسخهٔ انتشار روی staging و دامنهٔ واقعی هنوز باز است. این گزارش به معنی استقرار تولید نیست.

## اصلاحات

- فرم ثبت‌نام با درخواست backend هماهنگ شد: نام/نام خانوادگی، تأیید رمز، پذیرش قوانین و ذخیرهٔ موبایل ایران در تراکنش.
- شناسه‌های نامعتبر یا بزرگ‌تر از bigint در مسیرهای اصلی به‌جای خطای PostgreSQL، پاسخ ۴۰۴ می‌گیرند.
- متن‌های باقی‌ماندهٔ پخش/پیش‌نمایش ویدیو ترجمه شدند. خطای ۵۰۰ آگهی دارای ویدیوی آماده با فراخوانی متد درست پخش رفع شد.
- سقف موقت Livewire با ویدیوی ۱۰۰MB هماهنگ شد؛ PHP نیز upload=100M و post=110M دارد. worker هر دو صف default و videos را مصرف می‌کند؛ زمان retry از timeout بیشتر است.
- لینک پرش به محتوا، فوکوس واضح، نام دسترس‌پذیر لینک رکوردهای Filament، اندازهٔ کنترل پاک‌کردن و کنتراست نشان وضعیت اصلاح شدند.
- ۱۳۰ ترجمهٔ فارسی غایب Filament و دو placeholder خروجی export تکمیل شدند. فایل‌های vendor نصب‌شده دست‌کاری نشده‌اند.
- lockfileهای Composer/npm ثبت شدند. Docker/Compose به PHP 8.4 و Node 24، PostgreSQL، صف دیتابیسی و FFmpeg هماهنگ شدند. شروع تولید کلید/seed/migration خودکار ندارد. راهنمای نصب، TLS/Reverb، backup و rollback آماده شد.

## موارد باز پیش از انتشار واقعی

۱. تصویر Docker ساخته شد اما ایجاد کانتینر مستقل آن در دیسک ۳۲GB/VFS این محیط با کمبود فضا شکست خورد. پس از ثبت شناسه، تصویر موقت و کش ساخت حذف شدند؛ سرویس توسعه و volume دیتابیس حفظ شدند. اجرای HTTP و restart تصویر نهایی و Compose روی staging با فضای کافی هنوز لازم است. تغییرات نهایی ایجاد پوشه‌های startup و حذف داده‌های تست از build context پس از build مذکور افزوده و با بررسی نحوی کنترل شدند؛ خود این revision دوباره build نشده است. Dockerfile.dev نیز جداگانه build نشده است.
۲. TLS، دامنهٔ واقعی، webhook و سرویس‌های خارجی ایمیل/پیامک/پرداخت در این محیط متصل نیستند؛ فقط سرویس‌های محلی و حساب‌های ساختگی بررسی شدند.
۳. پیش از انتشار، backup دادهٔ واقعی، صحت APP_KEY ثابت، دسترسی رسانه و Reverb از دامنه، مسیرهای اصلی و rollback نسخهٔ سازگار با ریال روی staging بررسی شوند. [راهنمای انتشار و بازگشت](RELEASE_GUIDE_FA.md).

کیفیت محلی آماده است؛ تأیید انتشار تولید تا بستن موارد بالا باز می‌ماند.

## پیگیری staging

تلاش بعدی با سازندهٔ موقت روی RAM آغاز شد، اما دریافت تصویر پایه در هر دو مسیر Docker و BuildKit با خطای ۵۰۳ رجیستری/پراکسی متوقف شد. اجرای نسخهٔ انتشار همچنان باز است. [نتیجهٔ تشخیص و وضعیت منابع](STAGING_ATTEMPT.md).
