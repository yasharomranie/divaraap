# برنامهٔ فارسی‌سازی و راست‌چین OpenClassify

وضعیت: فازهای صفر تا ۶ تکمیل شده‌اند. اجرای برنامه در [گزارش فاز ۱](PHASE_1_REPORT.md) و فارسی، RTL و وزیرمتن محلی در [گزارش فاز ۲](PHASE_2_REPORT.md) ثبت شده‌اند. سایت و آگهی در [گزارش فاز ۳](PHASE_3_REPORT.md) ثبت شده‌اند. پنل و تعاملات در [گزارش فاز ۴](PHASE_4_REPORT.md) ثبت شده‌اند. مدیریت و CMS در [گزارش فاز ۵](PHASE_5_REPORT.md) ثبت شده‌اند؛ تکمیل مدیریت فایل در [گزارش مدیریت فایل](FILEMANAGER_LOCALIZATION.md) ثبت شده است. فاز ۶ تکمیل شد: شمسی، ساعت تهران، ارقام و موبایل ایران، مراکز استان‌ها و ورود/نمایش/ذخیرهٔ دقیق ریال پیاده و بررسی شدند. فاز ۷ از نظر اصلاحات و آزمون محلی انجام شد؛ تأیید staging/انتشار هنوز باز است. [گزارش فاز ۷](PHASE_7_REPORT.md). [گزارش فاز ۶](PHASE_6_REPORT.md).

## مبنا و محدوده

- منبع: https://github.com/openclassify/openclassify
- شاخهٔ مبنا: master، کامیت `42516cfcc16659e485183905b12e99efacfad2c0`
- مقصد: https://github.com/yasharomranie/divaraap ، شاخهٔ main
- فناوری: Laravel 13، PHP 8.4+، PostgreSQL 16+، Filament 5، TypeScript و Vite؛ Node مطابق نیاز نسخهٔ قفل‌شدهٔ Vite انتخاب شود.
- تاریخچهٔ پروژهٔ اصلی و فایل تست مخزن مقصد حفظ شده‌اند. این انتقال یک کپی با تاریخچه است؛ GitHub fork ایجاد نشده است.
- ۱۳ ماژول فایل ترجمهٔ انگلیسی دارند؛ ترجمهٔ فارسی در ماژول‌ها وجود ندارد. تنظیمات فعلی زبان پیش‌فرض ترکی، fallback انگلیسی و ارز USD دارند.
- قالب اصلی فقط برای زبان ar جهت rtl فعال می‌کند. وجود پشتیبانی جزئی عربی به معنای کامل بودن RTL نیست.

هدف نسخهٔ اول: تجربهٔ کامل فارسی در مسیر مشاهده، جست‌وجو، ثبت آگهی، حساب کاربری، گفتگو و مدیریت، با حفظ امکان استفاده از زبان انگلیسی.
شناسه‌ها و کد انگلیسی می‌مانند و ترجمهٔ هر ماژول داخل همان ماژول قرار می‌گیرد.

## قواعد اجرا و کنترل کیفیت

- هر فاز با commitهای کوچک، شرح تغییر، شواهد آزمون و push به مخزن مقصد تحویل شود.
- ترجمه بر مبنای کلیدهای انگلیسی انجام شود؛ placeholderها، جمع‌بندی‌ها و نام‌های فنی حفظ شوند. متن ثابت در PHP، Blade و TypeScript هم بررسی شود.
- به‌جای وارونه‌کردن عمومی صفحه از margin/padding/inset منطقی استفاده شود؛ آیکون‌های جهت‌دار هدفمند اصلاح شوند. تلفن، ایمیل، URL و شناسه با جهت مناسب نمایش داده شوند.
- صفحه‌ها در عرض‌های موبایل، تبلت و دسکتاپ بررسی شوند؛ dropdown، drawer، select، جدول، صفحه‌بندی، آپلود و گفتگو داخل دامنهٔ آزمون باشند.
- تاریخ در دیتابیس استاندارد باقی بماند؛ انتخاب تقویم نمایشی از ذخیره‌سازی جدا باشد. اعداد فارسی در ورودی پیش از اعتبارسنجی عادی‌سازی شوند.
- واحد مبلغ ذخیره‌شده و نمایشی صریح تعیین شود؛ تغییر USD به تومان صرفاً تعویض برچسب نباشد.
- داده‌های نمونهٔ ایران فقط در محیط مناسب seed شوند و دادهٔ موجود کاربر بازنویسی نشود.
- آزمون‌های موجود: `php artisan test`، `npm run type-check`، `npm run lint` و `npm run build`. اجرای آن‌ها در این مرحله ادعا نشده است.
- دیتابیس تست مستقل باشد؛ migrate:fresh فقط روی دیتابیس تست/نمونهٔ اختصاصی اجرا شود.

## تصمیم‌ها و ریسک‌های لازم

- پیش‌فرض پیشنهادی محصول فارسی است؛ زبان انگلیسی همچنان قابل انتخاب باشد.
- تصمیم فاز ۶ ثبت شد: ورود، نمایش و ذخیرهٔ ریال؛ نمایش شمسی و ساعت تهران. مبالغ قدیمی ارزهای دیگر حفظ می‌شوند. اتصال پیامک و درگاه جدید خارج از این برنامه است.
- فارسی‌سازی به معنی آماده بودن پرداخت و پیامک ایران نیست؛ اتصال سرویس‌های خارجی پروژهٔ جداگانه دارد.
- composer.json مجوز MIT اعلام می‌کند، اما فایل LICENSE مستقل در ریشه مشاهده نشده؛ پیش از انتشار تجاری شرایط استفاده و حقوق محتوای نمونه/تصاویر بررسی شود.
- ترجمه و RTL افزونه‌های Filament باید جداگانه بررسی شوند؛ ممکن است پوشش فارسی همهٔ افزونه‌ها یکسان نباشد.
- به‌روزرسانی‌های upstream ابتدا در شاخهٔ جدا بررسی و پس از تست ادغام شوند؛ main مقصد با force push بازنویسی نشود.

## تعریف اتمام

کاربر فارسی‌زبان بتواند ثبت‌نام کند، آگهی پیدا کند، آگهی ثبت/ویرایش کند و پیام بفرستد؛ مدیر بتواند محتوای اصلی را مدیریت کند. متن‌ها و خطاهای این مسیرها فارسی، رابط RTL و مقادیر مبلغ/تاریخ معتبر باشند. نسخهٔ انگلیسی دچار رگرسیون نشود و راهنمای اجرای قابل تکرار همراه نتایج تست ثبت شده باشد.

## آماده‌سازی محصول برای هاست اشتراکی

پس از فاز ۷، حالت shared برای MariaDB، پیام با polling، صف هم‌زمان و MP4 بدون FFmpeg اضافه شد. هر دو suite PostgreSQL و MariaDB با ۱۲۶ تست و ۲۰۱۷ assertion موفق بودند. این مرحله با ساخت نصاب/دکمهٔ deploy فرق دارد؛ بستهٔ نصب آماده و آزمون روی حساب واقعی سی‌پنل هنوز مرحلهٔ بعد هستند. [جزئیات و محدودیت‌ها](SHARED_HOSTING_FA.md).

تکمیل MySQL: نصب جدید به‌صورت پیش‌فرض از mysql استفاده می‌کند؛ نصب تازه و ۱۲۶ تست روی هر دو MySQL 8.0.46 و 8.4.11 تأیید شدند. [گزارش سازگاری MySQL](MYSQL_COMPATIBILITY_FA.md).

بستهٔ نصب اولیهٔ هاست اشتراکی و نصاب فارسی اضافه شدند؛ نصب استخراج‌شده با محدودیت shell و دیتابیس خالی بررسی شد. نصب واقعی روی حساب سی‌پنل و دکمهٔ به‌روزرسانی هنوز باز هستند. [گزارش بستهٔ نصب](INSTALLATION_PACKAGE_FA.md).
