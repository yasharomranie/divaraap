# نصب روی سی‌پنل، بدون ترمینال

این بسته برای PHP 8.4 و MySQL 8 یا MariaDB 11.4 آماده شده است. نصب روی دیتابیس خالی انجام می‌شود؛ برای ارتقای سایت موجود از این نصاب استفاده نکنید.

۱. یک دیتابیس جدید و کاربر جدید در سی‌پنل بسازید؛ کاربر را با دسترسی کامل به همان دیتابیس وصل کنید. نام کامل با پیشوند حساب را یادداشت کنید.
۲. در File Manager به پوشهٔ Home حساب بروید؛ یعنی یک سطح بالاتر از public_html. ZIP را همان‌جا آپلود و Extract کنید. ZIP و پوشهٔ divaraap نباید داخل public_html قرار بگیرند.
۳. پس از استخراج، این ساختار باید وجود داشته باشد: Home/divaraap برای کد خصوصی و Home/public_html برای فایل‌های عمومی. اگر public_html فعلی سایت دیگری دارد، فایل‌ها را روی آن نریزید؛ ابتدا یک محیط خالی/دامنهٔ آزمایشی جدا آماده کنید.
۴. PHP دامنه را روی 8.4 قرار دهید و HTTPS را فعال کنید. سپس https://YOUR-DOMAIN/install.php را باز کنید.
۵. کد را از فایل INSTALLATION-CODE.txt که در Home استخراج شده بخوانید؛ اطلاعات دیتابیس و حساب مدیر را پر کنید. نصاب پیش‌نیازها، خالی‌بودن دیتابیس و دسترسی پوشه‌ها را بررسی می‌کند.
۶. پس از موفقیت، نصاب خودکار قفل می‌شود. وارد /admin/login شوید. نام و توضیحات سایت، صفحات قوانین و حریم خصوصی، ایمیل SMTP و قیمت خدمات را خودتان تنظیم کنید. ایمیل فعلاً در لاگ ذخیره می‌شود و پیامک/پرداخت خارجی تنظیم نشده‌اند.
۷. ZIP و کد نصب را عمومی منتشر نکنید. ZIP را از هاست حذف کنید. فایل کد نصب را هم پس از موفقیت حذف کنید؛ کد نصب روی سرور بی‌اعتبار شده است. .env و installed.lock را نگه دارید. از دیتابیس و divaraap/storage/app پشتیبان بگیرید.

## پیش‌نیاز و محدودیت

storage و bootstrap/cache باید برای PHP قابل نوشتن باشند؛ 777 نگذارید. افزونه‌های لازم در فرم نصب نشان داده می‌شوند. سقف ویدیو پیش‌فرض 20MB است؛ PHP upload_max_filesize و post_max_size را در تنظیمات هاست هماهنگ کنید. ویدیو فقط MP4 آمادهٔ پخش است و روی سرور تبدیل نمی‌شود. پیام‌ها با polling دریافت می‌شوند؛ Cron، SSH، Composer و npm روی هاست برای این نصب لازم نیستند.

ساختار فوق برای دامنه‌ای است که document root آن public_html همین Home باشد. برای addon domain با پوشهٔ متفاوت، این بسته را بدون تنظیم چیدمان نصب نکنید. فایل‌های index.php و install.php مسیر خصوصی را ../divaraap در نظر می‌گیرند؛ چیدمان سفارشی باید پیش از نصب تنظیم و آزمایش شود.

## اگر نصب خطا داد

خطای اتصال یا دیتابیس غیرخالی چیزی را تغییر نمی‌دهد؛ اطلاعات را اصلاح کنید یا دیتابیس خالی بسازید. در خطای پس از شروع ساخت جدول‌ها، نصاب installation.pending را نگه می‌دارد و سایت عمومی فعال نمی‌شود. جدول‌های نیمه‌ساخته خودکار حذف نمی‌شوند.

برای شروع مجدد، فقط روی همین نصب تازه و بدون دادهٔ کاربر: یک دیتابیس خالی جدید بسازید، پوشهٔ خصوصی ناموفق را برای بررسی نگه دارید و بسته را دوباره در پوشهٔ خصوصی خالی استخراج کنید. آن را روی .env یا دادهٔ یک سایت فعال بازنویسی نکنید. فایل installation-error.log داخل divaraap فقط مرحله و نوع خطا را ثبت می‌کند؛ رمز را در پیام عمومی یا چت ارسال نکنید. محدودیت زمان اجرای وب‌سرور ممکن است با set_time_limit قابل افزایش نباشد.

این بسته نصاب اولیه دارد؛ دکمهٔ به‌روزرسانی خودکار هنوز در آن نیست. داده‌های نسخهٔ توسعه، کاربران نمونه و کلیدهای محیط توسعه داخل بسته نیستند.
